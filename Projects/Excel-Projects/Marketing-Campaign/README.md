# 📈 Marketing Campaign Analysis

## Project Overview
This Excel project analyzes the performance of multiple marketing campaigns across different channels and time periods. The goal is to understand campaign effectiveness and optimize marketing spend.

## File Information
- **File Name:** market campaign excel sheet EXP-02.xlsx
- **Size:** 395 KB
- **Type:** Excel Spreadsheet

## What's Inside

### Data Sheets
- **Raw Data:** Complete campaign performance metrics
- **Campaign Summary:** Overview of all active campaigns
- **Channel Analysis:** Performance breakdown by marketing channel

### Key Features
✅ **Campaign Performance Metrics**
- Campaign name and duration
- Budget allocation and actual spend
- Impressions, clicks, and conversions
- Cost per acquisition (CPA)
- Return on Ad Spend (ROAS)

✅ **Data Analysis**
- Conversion rate calculations
- ROI analysis by campaign
- Cost efficiency metrics
- Trend analysis over time

✅ **Visualizations**
- Campaign performance charts
- Channel comparison graphs
- ROI trend lines
- Budget vs. Spend analysis

## Excel Skills Used
- **VLOOKUP & INDEX-MATCH:** For data lookups
- **SUM, AVERAGE, IF:** For calculations
- **Pivot Tables:** For campaign summaries
- **Charts:** Bar, line, and pie charts
- **Conditional Formatting:** Highlighting key metrics

## Key Insights Expected
- Best performing marketing channels
- Campaign ROI comparison
- Cost efficiency trends
- Budget optimization recommendations

## How to Use
1. Download the Excel file
2. Review the "Campaign Summary" sheet for quick overview
3. Check "Channel Analysis" for detailed performance
4. Use charts to visualize trends and comparisons
5. Refer to "Raw Data" for detailed metrics
