# 🛒 Supermarket Sales Analytics

## Project Overview
This Excel project analyzes supermarket sales data to identify sales trends, top-performing products, and customer purchase patterns. It serves as a comprehensive sales intelligence tool for business decision-making.

## File Information
- **File Name:** supermarket_sales.xlsx
- **Size:** 302 KB
- **Type:** Excel Spreadsheet

## What's Inside

### Data Sheets
- **Sales Data:** Transaction-level sales information
- **Product Performance:** Sales by product category
- **Daily Sales:** Time-based sales trends
- **Customer Analysis:** Customer purchase patterns

### Key Features
✅ **Sales Metrics**
- Total sales and revenue
- Sales by product category
- Sales by time period (daily, weekly, monthly)
- Average transaction value
- Quantity sold per product

✅ **Performance Analysis**
- Top 10 products by revenue
- Product category performance
- Sales growth trends
- Profit margin analysis

✅ **Visualizations**
- Sales trends over time
- Product performance charts
- Category comparison graphs
- Revenue distribution pie charts

## Excel Skills Used
- **Pivot Tables:** Sales summaries by category and time
- **SUMIF/SUMIFS:** Conditional sales calculations
- **COUNTIF:** Transaction counting
- **Trend Analysis:** Using formulas to track patterns
- **Charts:** Line, bar, and pie charts for visualization
- **Conditional Formatting:** Highlighting top performers

## Key Insights Expected
- Best-selling product categories
- Peak sales periods
- Product performance rankings
- Revenue trends and forecasts

## How to Use
1. Download the Excel file
2. Start with "Daily Sales" sheet for trends
3. Check "Product Performance" for top sellers
4. Review "Customer Analysis" for buying patterns
5. Use charts for quick visual insights
